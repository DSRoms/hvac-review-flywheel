# Fulfillment SOP

## Audit
- check review profile, rating, recency, competitor averages
- identify response gaps and missed opportunities

## Install
- create review link and QR code
- write 3 SMS/email templates
- add 2 follow-up reminders

## Request flow
- send review request within 1–3 hours after completed job
- send second reminder 48 hours later

## Response flow
- reply to all new reviews within 24 hours
- escalate bad reviews to owner with suggested response

## Weekly
- post review count
- avg rating
- response time
- issue flags

## Monthly
- new reviews
- avg rating
- response SLA
- wins and issues
